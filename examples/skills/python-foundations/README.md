# Python foundations

Build a reliable first layer of Python by writing small functions, testing edge cases, and gradually combining them into a compact project.

## Target performance

Write and explain small Python functions that pass edge-case tests, using core syntax, collections, control flow, functions, exceptions, recursion, and simple classes in 30 minutes.

## Subskill map

- `syntax-types` — Read syntax and types; priority 1; prerequisites: none.
- `strings` — Transform strings; priority 1; prerequisites: `syntax-types`.
- `collections` — Use lists, sets, and dictionaries; priority 1; prerequisites: `syntax-types`.
- `loops-comprehensions` — Loop and build collections; priority 1; prerequisites: `collections`.
- `functions` — Compose functions and closures; priority 1; prerequisites: `loops-comprehensions`.
- `recursion` — Use a recursive base case; priority 2; prerequisites: `functions`.
- `exceptions` — Handle expected failures; priority 2; prerequisites: `functions`.
- `classes` — Model small objects; priority 2; prerequisites: `exceptions`, `collections`.

## How to start

1. `psi import-skill examples/skills/python-foundations`
2. `/skill`
3. `/practice`

Attempt each challenge before opening its hints. When a test fails, write one sentence about what the failure taught you and retry. The build quest combines the pieces; the boss is a final mixed test. Failures still earn progress.

The code challenges use Python 3 and include runnable tests. Code answers are checked by executing the starter or learner code with the supplied assertions; prose and numeric answers use deterministic grading.
