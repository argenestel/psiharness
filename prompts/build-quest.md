---
description: Scope a small learner-built project with testable subskill milestones.
argument-hint: "<project idea> [constraints]"
---
Use build-quests for the project idea beginning with $1.
Use $@ as the complete idea, goal, and constraints.
If the idea is missing, ask what small useful artifact the learner wants to make.
Use learner-memory and psi_memory_recall for relevant constraints or familiar domains.
Use psi_skill_plan to connect the project to ready subskills.
Choose one small artifact and three to five milestones.
For each milestone, name the artifact change, primary subskill, and acceptance check.
Use /quest as the learner-facing project route when helpful.
Start actual work through psi_practice_session.
Create only the current milestone as a kind build challenge through psi_challenge.
The learner must attempt the work before a solution is revealed.
Review the submitted artifact against its check and record it through psi_attempt.
Use psi_hint for one cue rather than writing the whole artifact for the learner.
Ask what surprised them after a test changes their expectation.
Keep prototypes cheap and use synthetic data instead of private records.
Reduce setup or scope if it consumes the practice budget.
Stop the session and use psi_recap for artifact state and the next milestone.
If tools are unavailable, keep the milestone map in chat and disclose that it was not saved.
